## 2. Fhuevtynfwbz

### **1. Независимое развитие доменов**
- Каждый домен может использовать свою базу данных и сервисы.
- Новые сервисы можно разрабатывать отдельно, не затрагивая DWH.

### **2. Улучшенная масштабируемость**
- Можно выделять ресурсы для конкретных доменов без перегрузки всей системы.
- BI-домен не замедляет работу медицинских и финансовых систем.

### **3. Повышенная безопасность**
- Медицинские данные остаются внутри своего домена, BI-домен не получает к ним доступа.
- Разграничение доступа к данным между доменами упрощается.

### **4. Ускорение отчетности и снижения нагрузки на DWH**
- Витрина данных получает информацию через API и стриминг из Kafka, а не из монолитного SQL-сервера.
- Запросы к BI-отчетам выполняются быстрее.

### **5. Гибкость в интеграции новых бизнесов**
- Новые компании (например, фармацевтика) можно подключить через API, не изменяя логику других доменов.
- Легче адаптироваться к новым требованиям бизнеса.
