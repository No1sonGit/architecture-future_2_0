**Роадмап внедрения изменений (глобальные задачи на год)**

| Этап | Результат | Ответственные команды | Требуемые ресурсы |
|------|----------|----------------------|-------------------|
| 1. Миграция DWH | Переход на BigQuery, отказ от SQL Server 2008 | Data Engineering, DBA | DevOps, облачные ресурсы |
| 2. Внедрение Kafka | Заменяет Apache Camel, унифицирует потоки данных | Архитекторы, Data Engineering | Kafka-кластеры, обучение |
| 3. BI-модернизация | Переход на Tableau/Looker, оптимизация отчетов | BI-аналитики, Data Engineering | Лицензии, серверы BI |
| 4. Развитие AI-сервисов | Интеграция ML-моделей для прогнозирования | AI-разработчики, DevOps | Вычислительные ресурсы |
| 5. Контейнеризация финтеха | Микросервисная архитектура, Kubernetes | Backend, DevOps | Kubernetes, Istio |

---

**Обоснование**

1. **Миграция DWH** – SQL Server 2008 не масштабируется, переход на BigQuery обеспечит высокую производительность и доступность данных.
2. **Внедрение Kafka** – Apache Camel устарел, Kafka обеспечит отказоустойчивость и высокую скорость обработки потоковых данных.
3. **BI-модернизация** – Power BI не справляется с нагрузкой, Tableau/Looker обеспечат гибкость и быструю генерацию отчетов.
4. **Развитие AI-сервисов** – Нужны прогнозные модели для медицины и финтеха, TensorFlow/PyTorch позволят создать продвинутые ML-решения.
5. **Контейнеризация финтеха** – Микросервисная архитектура упростит масштабирование и развертывание новых сервисов.
